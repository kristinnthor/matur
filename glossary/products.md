# Products — Icelandic names and substitutions

## Translation traps

These are wrong in obvious-looking ways. Get them right.

| English | Correct Icelandic | Common error |
|---|---|---|
| **cumin** | **kúmín** (or broddkúmen) | **`kúmen` is caraway — a different spice.** This is the single easiest mistake to make in Icelandic recipe translation. |
| coriander (seed) | kóríanderfræ | |
| coriander / cilantro (leaf) | kóríander | |
| shallot | skalottlaukur | not "lítill laukur" |
| spring onion | vorlaukur | |
| parsley | steinselja | |
| sage | salvía | |
| rosemary | rósmarín | |
| cremini / chestnut mushroom | kastaníusveppir | |
| pearl onion | perlulaukur | frozen is normal and fine |
| sour cream | sýrður rjómi | **always state the fat percentage** — see below |
| heavy / double cream | rjómi | |
| smoked paprika | reykt paprika | |
| red pepper flakes | chiliflögur | |
| red wine vinegar | rauðvínsedik | |
| beef chuck / stewing beef | nautagúllas | |
| lamb rib chops | lambakótilettur | |

## Fat percentages matter

Icelandic dairy is sold by percentage and the choice changes the result:

- **sýrður rjómi 36%** — for hot sauces; will not split as readily
- **sýrður rjómi 18%** — general use
- **sýrður rjómi 10%** — cold dishes, dressings, potato salad

Always specify. "Sour cream" alone is not enough information.

## Availability substitutions

Where an ingredient is hard to find in Iceland, name the substitute in `notes.variants`
rather than silently swapping it:

| Hard to find | Substitute |
|---|---|
| chipotle chilli powder | 1 tsk extra reykt paprika + ¼ tsk cayenne |
| fresh oregano | 1 msk dried oregano |
| buttermilk | mjólk + 1 msk sítrónusafi, látið standa 10 mín |
| piparostur (if unavailable) | rjómaostur með pipar, or fetaostur |

## Icelandic context

- **Outdoor grilling is not a year-round assumption.** Where a source says "grill", give a
  pan and an oven method too. This is a genuine usability issue, not pedantry.
- **Lamb is the default red meat.** Where a source is flexible, lamb is often the more
  natural Icelandic choice.
- Brand references (e.g. "frá Gott í matinn") in Icelandic sources should be
  generalised — name the product, not the brand.
